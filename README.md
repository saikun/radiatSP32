# radiatSP32

ESP32-S3 と OV2640 カメラモジュールを使った、放射線（β線・γ線）の2次元検出器です。

レンズを外して完全に遮光した CMOS センサーに放射線が当たると、1〜数画素だけが明るく光ります。この輝点をリアルタイムに検出し、位置 (X, Y) とエネルギー（輝度の高さ）を、シリアル経由で PC のビューアと SPI 接続の TFT 液晶に表示します。

ファームウェアには次の2つのモードがあり、ビルド時に切り替えます。

| モード | 用途 | PC 側ツール |
|---|---|---|
| `radiation` | 放射線検出（本命） | `tools/radiat_viewer.py` |
| `camera_stream` | カメラの動作確認用。映像をそのまま PC へ送る | `tools/camera_viewer.py` |

## ハードウェア

| 項目 | 内容 |
|---|---|
| MCU ボード | ESP32-S3-WROOM-1-N16R8 搭載のカメラ付き開発ボード（16MB Flash / 8MB Octal PSRAM） |
| センサー | OV2640（24pin FPC、DVP 接続）。放射線検出ではレンズを外して遮光する |
| ディスプレイ | ST7789 240x240（SPI 接続、任意） |
| PC 接続 | ボード左側の UART ブリッジ側 USB ポート（`TX`/`RX` のシルクがある側） |

### ピン配置

ピン定義は [include/pin_config.h](include/pin_config.h) にあります。

**OV2640（ボード内部配線）**

| 信号 | GPIO | 信号 | GPIO |
|---|---|---|---|
| XCLK | 15 | D7 (Y9) | 16 |
| SIOD (SDA) | 4 | D6 (Y8) | 17 |
| SIOC (SCL) | 5 | D5 (Y7) | 18 |
| VSYNC | 6 | D4 (Y6) | 12 |
| HREF | 7 | D3 (Y5) | 10 |
| PCLK | 13 | D2 (Y4) | 8 |
| PWDN / RESET | 未使用 (-1) | D1 (Y3) | 9 |
| | | D0 (Y2) | 11 |

**ST7789 TFT と LED**

| 信号 | GPIO |
|---|---|
| TFT MOSI (SDA) | 40 |
| TFT SCLK (SCL) | 39 |
| TFT CS | 38 |
| TFT DC | 41 |
| TFT RST | 42 |
| TFT BL（HIGH で点灯。3V3 直結でも可） | 1 |
| オンボード LED（ヒット時に点灯） | 2 |

> [!WARNING]
> GPIO 35〜37 は Octal PSRAM が使っているため、外部の配線に使わないでください。

## セットアップ

### ファームウェア

[PlatformIO](https://platformio.org/)（VSCode 拡張機能または CLI）を使います。ライブラリ（LovyanGFX）は初回ビルド時に自動で入ります。

```sh
# 放射線検出モード（デフォルト）
pio run -e radiation -t upload

# カメラストリームモード
pio run -e camera_stream -t upload
```

VSCode では、下部ステータスバーの環境選択（`env:radiation` / `env:camera_stream`）でモードを切り替えられます。

書き込みに失敗する場合は、`BOOT` ボタンを押したまま `EN/RST` ボタンを1回押し、`BOOT` を離してダウンロードモードに入ってから再度書き込んでください。

通信速度は両モード共通で 921600 bps です（`platformio.ini` の `custom_stream_baud`）。`pio device monitor` もこの速度で開きます。

### PC 側ビューア

Python 3.10 以降が必要です。

```sh
pip install -r tools/requirements.txt
```

## 放射線検出モード

### 仕組み

- **Core 0（検出）**: カメラからグレースケール画像（400x296）を取り込み、ダークフレームを引いて閾値を超えた画素を探します。周囲 3x3 で最も明るい画素だけを1イベントとして数えるので、電荷が隣の画素へ広がっても二重には数えません。
- **Core 1（出力）**: 検出したイベントのシリアル出力と TFT への描画、1秒ごとの統計出力、コマンドの受け付けを行います。

カメラ内蔵の画像補正（白点・黒点の除去、ガンマ補正、レンズシェーディング補正、自動露光・自動ゲイン・AWB）はすべて無効にしています。有効のままだと、放射線の輝点がノイズとして消されたり、明るさとエネルギーの比例関係が崩れたりするためです。

### キャリブレーション

起動直後に30フレームを撮り、画素ごとの最大値をダークフレーム（暗電流とホットピクセルの基準値）として記録します。以後は「現在の画素値 − ダークフレーム」が閾値を超えた画素を検出します。

キャリブレーションは、センサーを遮光した状態で行ってください。ゲインや露光を変えると暗電流も変わるため、自動で再キャリブレーションします。それ以外のタイミングでやり直すときは `c` コマンドを送ります。

### TFT 表示

- 上部 240x200: ヒットマップ。エネルギーに応じて 青→緑→黄→赤→白 の色で点を打ちます。
- 下部 240x40: CPS、CPM、累計カウント、フレームレート。

TFT が未接続でも動作は止まりません。TFT の制御を丸ごと外したい場合は、`platformio.ini` の `-DRADIATION_USE_TFT=1` を `0` にしてください。

### シリアルコマンド

改行区切りで送ります。

| コマンド | 内容 |
|---|---|
| `t=25` | 検出の閾値（1〜255） |
| `g=10` | ゲイン（0〜30）。変更後に自動で再キャリブレーション |
| `e=300` | 露光時間（0〜1200）。変更後に自動で再キャリブレーション |
| `c` | 再キャリブレーション |
| `r` | カウンタとヒットマップのリセット |
| `info` | チップ情報と現在の設定を出力 |

### シリアル出力

```
[HIT] X=123, Y=45, Energy=67, Sum=210, T=123456
[STAT] CPS=3, CPM=180, Total=1234, FPS=25.0, Drop=0, Cal=0
[CFG] W=400, H=296, TH=25, GAIN=10, EXP=300
[CAL] done mean=12.34 max=40 hot=3
```

| 項目 | 内容 |
|---|---|
| `Energy` | 中心画素の輝度差（輝度の高さ） |
| `Sum` | 周囲 3x3 の正の輝度差の合計。隣の画素へ広がった電荷も含めたエネルギーの目安 |
| `T` | ESP32 の起動からの時刻 [ms] |
| `CPM` | 直近60秒のカウント。60秒たまるまでは平均からの推計値 |
| `Drop` | 出力が追いつかずに捨てたイベント数（CPS・Total には含まれる） |
| `Cal` | キャリブレーション中は 1（この間は検出しない） |
| `hot` | ダークフレームが平均より閾値以上明るい画素の数 |

この形式は `tools/radiat_viewer.py` が解析しています。変更するときは両方を合わせてください。

### ビューア

```sh
python tools/radiat_viewer.py
```

ポートを選んで Connect を押すと、ESP32 をリセットせずに接続して現在の設定を読み込みます。

- **表示**: ヒットマップ（`points`: エネルギー別の色の点 / `heatmap`: 画素ごとのヒット数）、Energy または Sum のヒストグラム、直近120秒の CPS と CPM/60 の推移、ログ。
- **Apply**: 閾値・ゲイン・露光のうち、変わった値だけを送ります。
- **Calibrate / Reset / Info**: 上記のコマンドを送ります。Reset は PC 側の表示も消去します。
- **Record CSV**: 受信したヒットを `tools/logs/hits_*.csv` に記録します。
- **Save image**: 表示中のヒットマップを `tools/snapshots/` に保存します。

## カメラストリームモード

センサーと配線の確認用です。カメラの映像（JPEG またはグレースケール）を PC に送って表示します。

```sh
python tools/camera_viewer.py
```

ビューアからフォーマット（`jpeg` / `gray`）と解像度の変更、取り込みフレームレートの測定、画像の保存ができます。

## 動作確認の手順

1. **カメラの疎通確認**: `camera_stream` モードで映像が出ることを確認します。
2. **レンズを付けたままの検出テスト**: `radiation` モードで、レンズを指や黒い布で完全に覆って `c` を送ります。CPS がほぼ 0 に落ち着き、隙間から光を入れると大量に検出されれば正常です。光が強すぎると `Drop` が増えますが、異常ではありません。
3. **レンズ除去と遮光**: 電源を切ってレンズを外し、アルミテープと黒ビニールテープでセンサーを遮光します。再度キャリブレーションし、室内の照明を当てても CPS が 0 のままなら遮光は十分です。
4. **線源でのテスト**: 線源をセンサーに近づけ、ヒットが記録されることを確認します。
